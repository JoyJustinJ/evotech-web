# evotech-web

Official modern corporate portfolio website for **EvoTech** — Next-Gen IT Solutions & Software Engineering.

## Features
- **Modern Responsive Design:** Multi-page architecture (Home, About, Services, Projects, Team, Testimonials, Contact).
- **Rich Aesthetics & Micro-Animations:** Glassmorphism UI, interactive 3D card tilt/flip effects, animated metric counters, Ken-Burns hero banner carousel, and dynamic mouse tracking.
- **Brand Identity:** Custom vector brand logo, favicon badge, and curated modern tech color system.
- **Inquiry & Quote Portals:** Streamlined project estimation modal and direct contact communication.

## Tech Stack
- HTML5 & CSS3 (Custom design system, animations, responsive grid & flex layouts)
- Vanilla JavaScript (ES6+ modular interactive components)
- Font Awesome 6 & Google Fonts (Kumbh Sans & Plus Jakarta Sans)

## Project Structure
```
├── index.html           # Landing page with interactive hero & showcases
├── about.html           # Mission, tech stack, and corporate roadmap
├── services.html        # Comprehensive service offerings & feature grids
├── projects.html        # Interactive case studies with dynamic modal details
├── team.html            # Leadership & core engineering squad
├── testimonials.html    # Verified client case reviews & ratings
├── contact.html         # Direct consultation inquiry & office details
├── style.css            # Complete design system tokens and responsive styles
├── script.js            # UI controllers, modal state, counters & interactions
└── assets/              # High-resolution imagery, vectors & brand assets
```

## Getting Started
Simply open `index.html` in any modern web browser or serve via any static file server:
```bash
# Using Python
python -m http.server 8000

# Using Node/npx
npx serve
```
